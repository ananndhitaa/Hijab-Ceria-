# LEMBAR LAPORAN REPRODUKSI TEMUAN DEFECT / BUG
**Sistem:** NAYARA SaaS Platform  
**Fase:** 11–Final (Release Candidate)

---

## Format Pelaporan Defect Baru

Gunakan formulir ini apabila selama pelaksanaan Manual UAT ditemukan bug atau anomali:

```markdown
### [BUG-ID] Judul Ringkas Bug

- **Tingkat Keparahan (Severity):** [CRITICAL / MAJOR / MINOR / COSMETIC]
- **Modul / Halaman:** [Contoh: /owner/ads/create]
- **Peran Pengguna (Role):** [Contoh: OWNER]
- **Browser & OS:** [Contoh: Chrome 120 di Windows 11]

#### 1. Langkah-Langkah Reproduksi (Steps to Reproduce)
1. Login sebagai ...
2. Buka menu ...
3. Masukkan data ...
4. Klik tombol ...

#### 2. Perilaku yang Diharapkan (Expected Behavior)
Jelaskan apa yang seharusnya terjadi sesuai dokumen spesifikasi.

#### 3. Perilaku Aktual (Actual Behavior)
Jelaskan error, pesan kegagalan, atau anomali yang terjadi.

#### 4. Bukti Pendukung (Screenshot / Log)
Lampirkan tangkapan layar atau salinan teks log error.
```
